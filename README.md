# CM Energy Score

A self-diagnostic tool for Community Managers, Discord builders, and Community Ops. Through 15 behavioral questions across 5 axes (reactivity, repetition, invisibility, dependency, burnout), it produces:

- A severity score (0–100%, or /10) on a Signal ↔ Compensation scale
- A dominant operational profile (e.g. The Firefighter, The Concierge, The Guardian) — reflecting the role the person's system pushes them to play, not a personality trait

Core thesis: reactivity, exhaustion, and lack of recognition aren't personal failures — they're symptoms of a system (the Discord server's architecture) that was never designed to carry the load being asked of it.
